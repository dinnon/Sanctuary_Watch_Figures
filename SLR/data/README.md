# NOAA sea-level rise data exports

These **data products** are generated by \`python tools/build_embed.py\` from the same
saved \`SLR/snapshots/*.json\` files used to build the Sanctuary Watch interactive
charts. No web request is made during export. Refresh a snapshot first using
\`python tools/add_station.py STATION_ID\`, then rebuild.

## Files

- \`data/STATION_ID.json\`: IOOS Graphic Data-style \`metadata\` header and
  column-oriented \`data\` arrays (all arrays have the same length).
- \`data/STATION_ID.csv\`: descriptive key/value metadata rows, blank line,
  standard CSV header, then one row per monthly observation.
- \`data/all_stations.csv\`: same columns for every **saved** station.
- \`data/manifest.json\`: station coverage and retrieval dates.

The sample format is based on the [IOOS Sanctuary Watch example JSON](https://github.com/ioos/sanctuarywatch_graphicdata/blob/main/plugins/graphic_data_plugin/example_files/example.json)
and [CSV](https://github.com/ioos/sanctuarywatch_graphicdata/blob/main/plugins/graphic_data_plugin/example_files/example.csv).
This is a **format adaptation**, not a claim that the WordPress plugin natively
understands every new SLR column.

## Columns and scientific treatment

- \`date_yyyy-mm\`: monthly date, not a point-in-time instantaneous measurement.
- \`station_id\`, \`station_name\`: source station identity.
- \`msl_m\`: original NOAA monthly mean sea level (\`msl\`).
- \`msl_deseasonalized_m\`: NOAA deseasonalized monthly MSL.
- \`noaa_trend_m\`, \`noaa_ci_lower_m\`, \`noaa_ci_upper_m\`:
  original \`trendLine\`, \`lowerConfidence\`, \`upperConfidence\` values,
  **including where NOAA's monthly series supplies extrapolations**.
- \`display_trend_m\`, \`display_ci_lower_m\`, \`display_ci_upper_m\`:
  identical NOAA numerical values but null outside the \`startDate\`–\`endDate\`
  of NOAA's SINGLE trend summary. These match the figure's clipping rule.

All elevation values are meters relative to NOAA MSL. No regressions, confidence
intervals, or interpolated values are calculated by this pipeline. Blank CSV
cells / JSON nulls mean missing or outside the display period; they are not zero.
Metadata contains URLs, source retrieval timestamp, station ID, trend-period
dates and reported rate, and source units. Do not assume a numeric CI percentage
from a different NOAA product.

For archival fidelity consult the \`snapshots/\` originals, which preserve more
of NOAA's source metadata and the separate \`observedSL\` amount-of-change product.
The CSV/JSON here focus on the \`sealvltrends SINGLE\` time series.

**Coverage warning:** The figures can query NOAA live in a visitor's browser.
This does **not** update repository snapshots or these downloadable exports.
Only stations with a saved \`snapshots/STATION_ID.json\` are exported. Refresh
and commit those snapshots to update public products. CSV metadata lines should
be skipped by generic tabular readers; the actual column header follows a blank
line.
